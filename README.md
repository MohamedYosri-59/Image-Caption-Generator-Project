# Image-Caption-Generator-Project
this project is made as the final assignment project for an AI Diploma held by Array academy
1- used dataset: Flickr8k dataset which can be found easily on kaggle (couldn't upload it here due to upload size restriction)
2- the aim is to make a streamlit application that generates captions for images
3- the file 'Image_Captioning_Project_(VSCode).ipynb' contains the whole code used from the data entry step to the application creation
4- the file 'ImageCaptionGeneratorByMohamedYosri(longRun).py' contains only the final application creation code that was deployed to streamlit
5- the file 'Image_Captioning_Project_(VSCode).ipynb' has markdown cells separating the code into stages to be simple to understand as well as comments for almost every line to explain the function of the line
important note: model accuracy could have been much better but i had two major issues : 1- google colab was always getting disconnected due to dialy quota consumption 2- VS code was storing temporary data on my pc during run so i had to reduce number of training epochs to 2 only. 
Streamlit link: https://image-caption-generator-project-by-mohamed-yosri.streamlit.app/
